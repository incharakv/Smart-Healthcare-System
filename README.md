# 🏥 Smart Healthcare Appointment Booking and Queue Management System

## 📌 About the Project

The Smart Healthcare Appointment Booking and Queue Management System is a web-based application designed to make hospital visits easier and more organized.

Patients can register, explore available doctors, book appointments, receive a token number, and monitor their queue status.

## ✨ Features

- 👤 Patient Registration
- 👨‍⚕️ Doctor Search and Information
- 📅 Appointment Booking
- 🎫 Automatic Token Generation
- ⏳ Queue Management
- 📊 Queue Status Tracking
- 🏥 Smart Hospital Management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## 🔄 How It Works

1. Patient registers in the system.
2. Patient views available doctors.
3. Patient selects a doctor and books an appointment.
4. System generates a token number.
5. Patient can view their queue status.
6. The system helps manage appointments and reduce waiting-time confusion.

## 🎯 Project Objective

The main objective is to provide a simple digital healthcare system that improves appointment management and helps patients understand their position in the hospital queue.
